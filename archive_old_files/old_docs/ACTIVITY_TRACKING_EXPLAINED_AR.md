## 🎯 الأنشطة المُكتشفة تلقائياً

### 1️⃣ **Working** (العمل)
```python
# الشروط:
✅ جالس (Sitting)
✅ يوجد لابتوب/كيبورد قريب
✅ اليدين للأمام (على الكيبورد)
✅ حركة متوسطة (يكتب/يتحرك)
```

**النموذج المستخدم:**
- MediaPipe Pose (كشف الجلوس/الوضعية) ✅ جاهز
- YOLOv8 (كشف اللابتوب/الكيبورد) ✅ جاهز
- حساب الحركة (بسيط، بدون نموذج) ✅

---

### 2️⃣ **On Phone** (على الهاتف)
```python
# الشروط:
✅ اليد قريبة من الوجه

✅ حركة قليلة
```

**النموذج المستخدم:**
- MediaPipe Pose (كشف اليد قرب الوجه) ✅ جاهز
- YOLOv8 (كشف الموبايل) ✅ جاهز

### 3️⃣ **Idle/Sleeping** (خامل/نائم)

**النموذج المستخدم:**
- MediaPipe Pose (كشف الوضعية) ✅ جاهز
- حساب الحركة البسيط ✅

### 4️⃣ **Meeting** (اجتماع)

```python
# الشروط:
```

**النموذج المستخدم:**

## 🛠️ النماذج بالتفصيل

### 1. YOLOv8 (كشف الأشخاص والأشياء)

**ما هو:**
- نموذج كشف أشياء (Object Detection)
- مُدرَّب على COCO dataset (80 فئة)
- يكشف: أشخاص، لابتوب، موبايل، كيبورد، إلخ

**الحالة:**
```
✅ مُدرَّب مسبقاً على 118,000 صورة
✅ دقة عالية (mAP 50-95: 37.3%)
✅ سريع جداً (150+ FPS على GPU)
✅ يعمل على CPU أيضاً (20-30 FPS)
```

**الملف الموجود:**
```
yolov8n.pt (6.5 MB) ✅ موجود في المشروع
```

**ما يكشفه:**
```python
# الأشخاص
class 0: person

# الأشياء المفيدة
class 63: laptop
class 64: mouse  
class 66: keyboard
class 67: cell phone (mobile)
class 62: tv/monitor
```

**لا تحتاج تدريب!** - جاهز للاستخدام مباشرة

---

### 2. MediaPipe Pose (كشف الوضعية)

**ما هو:**
- يكشف 33 نقطة في الجسم
- يحدد الوضعية (جالس/واقف)
- يكشف حركة اليدين والرأس

**الحالة:**
```
✅ مُدرَّب مسبقاً من Google
✅ دقة عالية
✅ سريع (30+ FPS على CPU)
✅ يُحمَّل تلقائياً عند التثبيت
```

**ما يكشفه:**
```python
# نقاط الجسم
- الرأس (nose, eyes, ears)
- الكتفين (shoulders)
- المرفقين (elbows)
- المعصمين (wrists)
- الوركين (hips)
- الركبتين (knees)
- الكاحلين (ankles)

# الاستنتاجات
- جالس أم واقف؟
- اليدين للأمام أم للخلف؟
- اليد قرب الوجه؟
- زاوية الجسم
```

**لا تحتاج تدريب!** - جاهز للاستخدام

---

### 3. القواعد الذكية (Rule-based System)

**ما هي:**
- نظام قواعد منطقية بسيط
- يجمع المعلومات من النماذج
- يستنتج النشاط النهائي

**مثال:**
```python
# قاعدة "Working"
if (
    sitting == True and           # من MediaPipe
    laptop_nearby == True and     # من YOLO
    hands_forward == True and     # من MediaPipe
    motion_level > 0.05           # حساب بسيط
):
    activity = "working"
    confidence = 0.85
```

**ملف القواعد:**
```python
# src/activity_rules.py ✅ موجود
DEFAULT_RULES = {
    "working": {...},
    "on_phone": {...},
    "idle": {...},
    "meeting": {...},
    "away": {...}
}
```

**قابل للتخصيص!** - يمكنك تعديل القواعد بسهولة

## ⏱️ حساب الوقت (Time Tracking)

### كيف يعمل؟

```python
# لكل شخص، يتم تتبع:
track_id: 123
employee_id: "EMP001"
current_activity: "working"
start_time: "09:00:15"

# عند تغيير النشاط:
# 1. حفظ القطعة السابقة
segment = {
    "activity": "working",
    "start": "09:00:15",
    "end": "09:45:30",
    "duration": 2715 seconds (45 min 15 sec)
}

# 2. بدء قطعة جديدة
current_activity: "on_phone"
start_time: "09:45:30"
```

### التقرير النهائي:

```json
{
  "employee_id": "EMP001",
  "date": "2025-01-06",
  "total_time": "8h 30m",
  "breakdown": {
    "working": "6h 15m (73.5%)",
    "on_phone": "45m (8.8%)",
    "idle": "30m (5.9%)",
    "meeting": "1h (11.8%)",
    "away": "0m (0%)"
  },
  "productivity_rate": 85.3
}
```
