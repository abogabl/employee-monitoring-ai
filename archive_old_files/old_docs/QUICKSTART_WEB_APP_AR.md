# 🚀 دليل البدء السريع - تطبيق الويب

## 📋 خطوات سريعة

### 1. تشغيل التطبيق

```bash
# من مجلد المشروع
python run_web_app.py
```

أو:

```bash
cd web_app
python app.py
```

### 2. الوصول للتطبيق

افتح المتصفح على:
```
http://127.0.0.1:5000
```

### 3. تسجيل الدخول

استخدم أحد المستخدمين الافتراضيين:

```
المستخدم: admin
كلمة المرور: admin
الصلاحية: كل الصلاحيات
```

---

## 👥 إضافة موظف بالصورة

### الخطوات:

1. **افتح صفحة الموظفين**
   - من القائمة العلوية → الموظفون
   - أو من لوحة القيادة → بطاقة "إدارة الموظفين"

2. **اضغط على "إضافة موظف جديد"**
   - زر أزرق في أعلى الصفحة

3. **أضف الصورة**
   - اسحب الصورة إلى المربع
   - أو انقر على المربع لاختيار ملف
   - سترى معاينة للصورة

4. **املأ البيانات**
   - معرف الموظف: `EMP001` (مثال)
   - الاسم: `أحمد محمد` (مثال)
   - القسم: `تقنية المعلومات`
   - الوظيفة: `مطور برمجيات`
   - تاريخ التعيين
   - الحالة: نشط

5. **احفظ**
   - اضغط زر "حفظ"
   - سيتم حفظ الموظف مع صورته

---

## 🔍 البحث عن موظف

### طريقة 1: البحث بالاسم أو المعرف

```
1. اذهب لصفحة الموظفين
2. في شريط البحث، اكتب الاسم أو المعرف
3. اضغط "تطبيق"
```

### طريقة 2: الفلترة حسب القسم

```
1. اذهب لصفحة الموظفين
2. اختر القسم من القائمة المنسدلة
3. اضغط "تطبيق"
```

### طريقة 3: دمج البحث والفلترة

```
اكتب اسم + اختر قسم + اضغط "تطبيق"
```

## 📄 عرض تفاصيل موظف

### الخطوات:

1. **من قائمة الموظفين**
   - اضغط على أيقونة العين 👁️ بجانب الموظف

2. **ستظهر صفحة التفاصيل تحتوي:**
   - الصورة الشخصية (كبيرة)
   - كل المعلومات
   - سجل الحضور اليوم
   - إحصائيات سريعة
   - أزرار التعديل والحذف

---

## ✏️ تعديل بيانات موظف

### طريقة 1: من صفحة التفاصيل

```
1. افتح تفاصيل الموظف
2. اضغط "تعديل البيانات"
3. عدّل ما تريد
4. احفظ التغييرات
```

### طريقة 2: إعادة إضافة بنفس المعرف

```
1. اضغط "إضافة موظف جديد"
2. اكتب نفس المعرف (EMP001)
3. غيّر البيانات الأخرى
4. احفظ (سيتم التحديث تلقائياً)
```

---

## 🗑️ حذف موظف

### الخطوات:

1. **من قائمة الموظفين**
   - اضغط أيقونة سلة المهملات 🗑️

2. **أو من صفحة التفاصيل**
   - اضغط زر "حذف الموظف"

3. **أكد الحذف**
   - سيظهر تأكيد
   - اضغط "OK" للمتابعة

⚠️ **تحذير:** الحذف لا يمكن التراجع عنه!

## 🎨 فهم الألوان والرموز

### Badges (الشارات):

- 🟢 **أخضر (نشط)**: الموظف أو الكاميرا نشطة
- 🔵 **أزرق (معلومة)**: قسم أو معلومة عامة
- 🔴 **أحمر (غير نشط)**: متوقف أو غير فعال
- 🟡 **أصفر (تحذير)**: يحتاج انتباه

### الأيقونات:

- 👁️ **عين**: عرض التفاصيل
- ✏️ **قلم**: تعديل
- 🗑️ **سلة مهملات**: حذف
- ➕ **زائد**: إضافة جديد
- 🔍 **عدسة مكبرة**: بحث
- 🎯 **هدف**: فلترة

## 🔐 مستويات الصلاحيات

### Admin (مدير)
- ✅ كل الصلاحيات
- ✅ إضافة/تعديل/حذف الموظفين
- ✅ تغيير الإعدادات
- ✅ عرض كل التقارير

### Manager (مشرف)
- ✅ عرض الموظفين
- ✅ عرض الحضور
- ✅ إنشاء التقارير
- ❌ لا يمكن حذف الموظفين

### Operator (مشغّل)
- ✅ التحكم بالكاميرات
- ✅ عرض الموظفين
- ❌ لا يمكن التعديل

### Viewer (مشاهد)
- ✅ عرض فقط
- ❌ لا يمكن التعديل أو الحذف

## 💡 نصائح سريعة

### للصور:
- ✅ استخدم صور بخلفية واضحة
- ✅ الوجه يجب أن يكون واضحاً
- ✅ حجم مناسب: 200x200 إلى 800x800 بكسل
- ✅ أنواع مدعومة: JPG, PNG
- ⚠️ حجم أقصى: 5 MB

### للبحث:
- 💡 يمكنك البحث بجزء من الاسم
- 💡 البحث لا يفرق بين الحروف الكبيرة والصغيرة
- 💡 يمكنك البحث بالمعرف أو الاسم

### لتنظيم الموظفين:
- 📁 استخدم أقسام واضحة (IT, HR, Sales, ...)
- 📋 استخدم معرفات منظمة (EMP001, EMP002, ...)
- 🏷️ حدد الوظائف بوضوح

---

## 🐛 حل المشاكل الشائعة

### الصورة لا تُرفع

**الحل:**
1. تأكد أن الصورة أصغر من 5 MB
2. تأكد أن الامتداد JPG أو PNG
3. جرب صورة أخرى

### الموظف لا يظهر

**الحل:**
1. تأكد أنك ضغطت "حفظ"
2. حدّث الصفحة (F5)
3. تحقق من شريط البحث (ربما مُفعَّل)

### لا أستطيع الحذف

**الحل:**
1. تأكد أنك مسجل كـ **admin**
2. Operator و Viewer لا يمكنهم الحذف

### التصميم غير واضح

**الحل:**
1. امسح الـ Cache: Ctrl + Shift + R
2. جرب متصفح آخر
3. تأكد من تشغيل التطبيق الأخير
