# 🚀 دليل النظام المحسن - المستوى الثاني

## 🎯 نظرة عامة

مرحباً بك في **المستوى الثاني** من نظام المراقبة الذكي! يتضمن هذا المستوى تحسينات متقدمة تجعل النظام أكثر ذكاءً وقوة.

## ✨ الميزات الجديدة

### 🎬 1. نظام الكاميرات المتعددة المتزامن
- **مراقبة عدة كاميرات** في نفس الوقت
- **تتبع الأشخاص عبر الكاميرات** المختلفة
- **إدارة موحدة للموارد** والأداء
- **واجهة موحدة** لجميع الكاميرات

### 🧠 2. الذكاء الاصطناعي المتقدم
- **كشف الشذوذ** في السلوك تلقائياً
- **التنبؤ بالأنشطة** التالية
- **تحليل الأنماط** السلوكية المعقدة
- **تقييم المخاطر** الذكي
- **توصيات تلقائية** للتحسين

### 📊 3. لوحة التحكم في الوقت الفعلي
- **مراقبة مباشرة** لجميع الكاميرات
- **إحصائيات تفاعلية** ومخططات بيانية
- **إنذارات فورية** للأحداث المهمة
- **واجهة حديثة** مع تأثيرات بصرية متقدمة

## 🚀 كيفية التشغيل

### التشغيل السريع - النظام الكامل
```bash
# النظام الكامل مع جميع الميزات
python run_level2_system.py --mode full --enable-ai

# ثم اذهب إلى:
# لوحة التحكم: http://127.0.0.1:8080/dashboard
# معالجة الفيديو: http://127.0.0.1:8080/test-video
```

### 📹 الكاميرات المتعددة فقط
```bash
# تشغيل الكاميرات مع الذكاء الاصطناعي
python run_level2_system.py --mode cameras --enable-ai

# بدون ذكاء اصطناعي (أسرع)
python run_level2_system.py --mode cameras
```

### 📊 لوحة التحكم فقط
```bash
# لوحة التحكم والواجهة الويب فقط
python run_level2_system.py --mode dashboard

# مع إتاحة على الشبكة
python run_level2_system.py --mode dashboard --host 0.0.0.0 --port 8080
```

## ⚙️ إعداد الكاميرات

### إنشاء ملف الإعدادات
سيتم إنشاء ملف `config/cameras_config.json` تلقائياً عند التشغيل الأول:

```json
{
  "cameras": [
    {
      "id": "cam1",
      "name": "الكاميرا الرئيسية",
      "source": 0,
      "location": "المكتب الرئيسي",
      "enabled": true,
      "settings": {
        "yolo_model": "s",
        "imgsz": 416,
        "conf_threshold": 0.35,
        "enable_face_recognition": true,
        "enable_activity_recognition": true,
        "enable_attendance": true
      }
    }
  ]
}
```

### إضافة كاميرات متعددة
```json
{
  "cameras": [
    {
      "id": "cam1",

    {
      "id": "cam2",

      "source": 1,
```

## 🧠 الذكاء الاصطناعي المتقدم

### الميزات المتوفرة

#### 🔍 كشف الشذوذ
- يتعلم النظام من السلوك الطبيعي
- يكتشف الأنماط غير المعتادة تلقائياً
- ينبه عند حدوث سلوك شاذ

#### 🔮 التنبؤ بالسلوك
- يتوقع النشاط التالي للشخص
- يحلل الأنماط الزمنية
- يقدم توصيات ذكية

#### 📈 تحليل المخاطر
- **منخفض**: سلوك طبيعي
- **متوسط**: يحتاج متابعة
- **عالي**: يتطلب تدخل فوري

### متطلبات الذكاء الاصطناعي
```bash
# تثبيت مكتبات التعلم الآلي
pip install scikit-learn pandas numpy joblib

# أو استخدام ملف المتطلبات المحسن
pip install -r requirements_enhanced.txt
```

## 📊 لوحة التحكم المتقدمة

### الواجهات المتاحة

#### 🎯 الصفحة الرئيسية
- **العدادات المباشرة**: الكاميرات، الأشخاص، الأنشطة
- **حالة النظام**: وقت التشغيل، الاتصال، الأداء
- **التحكم السريع**: بدء/إيقاف الكاميرات، إنشاء التقارير

#### 📹 مراقبة الكاميرات
- **بث مباشر** من جميع الكاميرات
- **حالة كل كاميرا** (متصل/غير متصل)
- **إحصائيات الأداء** لكل كاميرا

#### 👥 الأشخاص النشطين
- **قائمة الأشخاص** الموجودين حالياً
- **الأنشطة الحالية** لكل شخص
- **التتبع عبر الكاميرات** المختلفة

#### 📈 التحليلات والرسوم البيانية
- **توزيع الأنشطة**: رسم دائري للأنشطة
- **أداء الكاميرات**: رسم خطي للإطارات المعالجة
- **اتجاهات الوقت الفعلي**: تحديث مستمر

### استخدام لوحة التحكم

#### الأزرار الرئيسية
- **🟢 بدء جميع الكاميرات**: تشغيل النظام
- **🔴 إيقاف جميع الكاميرات**: إيقاف مؤقت
- **📄 إنشاء تقرير**: حفظ الإحصائيات الحالية

#### المؤشرات
- **🟢 متصل**: النظام يعمل بشكل طبيعي
- **🔴 غير متصل**: مشكلة في الاتصال
- **⚠️ تحذير**: تم اكتشاف مشكلة

## 📋 أمثلة الاستخدام


## 🔄 التحديث والصيانة

### التحديث التلقائي للنماذج
- النظام يتعلم تلقائياً من البيانات الجديدة
- يحفظ النماذج في مجلد `models/behavior/`
- يحدث النماذج كل 5 دقائق

### النسخ الاحتياطي
```bash
# نسخ احتياطي للنماذج
cp -r models/behavior/ backup/models_$(date +%Y%m%d)/

# نسخ احتياطي للإعدادات
cp config/cameras_config.json backup/config_$(date +%Y%m%d).json
```

### مراقبة الأداء
- تحقق من استخدام الذاكرة والمعالج
- راقب مساحة القرص الصلب
- تابع سجلات الأخطاء

## 🎯 نصائح للاستخدام الأمثل

### الأداء
- استخدم `yolo_model: "n"` للسرعة القصوى
- استخدم `yolo_model: "s"` للتوازن المثالي
- استخدم `yolo_model: "m"` للدقة العالية

### الدقة
- ضع الكاميرات في مواقع جيدة الإضاءة
- تجنب الخلفيات المعقدة
- اضبط `conf_threshold` حسب البيئة

### الاستقرار
- استخدم كاميرات ثابتة غير متحركة
- تأكد من استقرار الشبكة للكاميرات IP
- راقب درجة حرارة النظام
