**الحل:**

**الحل:**

- ✅ تحديث تلقائي عند إيجاد صورة أفضل
- ✅ استخدام `QualityAssessor` من نظام التعلم الذاتي

### 3. ✅ التكامل مع نظام التعلم الذاتي
**الميزة الجديدة:**
- ✅ جمع تلقائي للصور عالية الجودة
- ✅ إضافة للتدريب المستمر

## المعالج المحسّن: `ImprovedVideoProcessor`

### الميزات الرئيسية:

#### 1. نظام الهويات الثابتة
```python
class PersonIdentity:
    - person_id: معرف ثابت طوال الفيديو
    - track_ids: كل Track IDs المرتبطة بالشخص
    - embeddings: للمطابقة عبر الظهورات
    - best_snapshot: أفضل صورة محفوظة
    - best_quality: جودة أفضل صورة
```

#### 2. المطابقة الذكية
- عند ظهور Track ID جديد:
  1. استخراج Face Embedding
  2. البحث في الهويات الموجودة
  3. إذا تطابق → ربط بنفس الهوية
  4. إذا لم يتطابق → إنشاء هوية جديدة

#### 3. تحسين الصور
```python
quality = (size_score * 0.3 + 
           sharpness_score * 0.4 + 
           brightness_score * 0.3)

if quality > best_quality:
    update_snapshot()
```

#### 4. التعلم الذاتي
- جمع كل 30 إطار
- فقط للأشخاص المعروفين
- حد أقصى 50 صورة/يوم
