# 👤 دليل إضافة موظف جديد - خطوة بخطوة
## 📝 نظرة عامة
لإضافة موظف جديد والتعرف عليه، تحتاج **خطوتين منفصلتين**:
1. **إضافة البيانات في تطبيق الويب** (اختياري - للعرض فقط)
2. **تدريب نموذج التعرف على الوجه** (مطلوب - للتعرف الفعلي)
---
## 🌐 الخطوة 1: إضافة الموظف في تطبيق الويب (اختياري)
### الهدف:
عرض معلومات الموظف وصورته في واجهة الويب فقط
### الطريقة:
1. **افتح تطبيق الويب**
   ```
   http://127.0.0.1:8080
   ```
2. **اذهب لصفحة الموظفين**
   - من القائمة → الموظفون
3. **اضغط "إضافة موظف جديد"**
4. **املأ البيانات:**
   - معرف الموظف: `EMP001`
   - الاسم: `أحمد محمد`
   - القسم: `IT`
   - الوظيفة: `مطور`
   - تاريخ التعيين
   - الصورة: صورة واحدة للعرض فقط
5. **احفظ**
**النتيجة:** ✅ سيظهر الموظف في القائمة بصورته
---
## 🧠 الخطوة 2: تدريب نموذج التعرف (مطلوب)
### الهدف:
تعليم النظام التعرف على وجه الموظف من الكاميرا
### أ. تجهيز صور التدريب
#### 1. إنشاء مجلد للموظف:
```bash
# Windows PowerShell
mkdir employees_database\faces\EMP001
```
أو يدوياً:
```
employees_database/
└── faces/
    └── EMP001/          ← أنشئ هذا المجلد
```

#### 2. إضافة الصور (5-10 صور):

**متطلبات الصور:**
- ✅ عدد: 5-10 صور
- ✅ تنوع: زوايا وإضاءة مختلفة
- ✅ جودة: واضحة وحادة
- ✅ حجم: 200x200 بكسل على الأقل
- ✅ تنسيق: JPG أو PNG
- ✅ الوجه: واضح وفي المنتصف

**مثال على هيكل الصور:**
```
employees_database/faces/EMP001/
├── photo1.jpg    ← وجه مباشر
├── photo2.jpg    ← نصف جانب يمين
├── photo3.jpg    ← نصف جانب يسار
├── photo4.jpg    ← إضاءة مختلفة
├── photo5.jpg    ← ابتسامة
├── photo6.jpg    ← جدية
└── photo7.jpg    ← مسافة مختلفة
```
### ب. فحص جودة الصور (اختياري لكن مُوصى به)
```bash
python tools/validate_face_images.py
```
**سيفحص:**
- ✅ هل الصور واضحة؟
- ✅ هل الوجه مكتشف؟
- ✅ هل الإضاءة جيدة؟
- ✅ هل الحجم مناسب؟

### ج. تدريب النموذج

#### الطريقة 1: تدريب بسيط

```bash
python train_faces.py
```

#### الطريقة 2: تدريب مع فحص الجودة (مُوصى به)

```bash
python tools/train_faces_improved.py --check-quality
```

**ماذا يحدث:**
1. يقرأ كل الصور من `employees_database/faces/`
2. يستخرج features الوجه من كل صورة
3. يحفظ النموذج في `models/face_encodings.pkl`

**المدة:** 2-5 دقائق لكل موظف

### د. التحقق من النتائج

```bash
python tools/inspect_encodings.py
```

**سيعرض:**
```
✅ عدد الموظفين المُدرَّبين
✅ عدد الصور لكل موظف
✅ تفاصيل كل موظف
```

## 🔄 إضافة موظف آخر

### لإضافة موظف ثاني أو ثالث:

1. **أنشئ مجلد جديد:**
   ```bash
   mkdir employees_database\faces\EMP002
   ```

2. **أضف صوره (5-10 صور)**

3. **أعد التدريب:**
   ```bash
   python train_faces.py
   ```

**ملاحظة مهمة:** 
- ✅ كل مرة تضيف موظف جديد، أعد التدريب
- ✅ التدريب يشمل كل الموظفين (القدامى + الجديد)
- ✅ لن يُحذف الموظفون القدامى

---

- ✅ يُسجل الحضور تلقائياً
- ✅ دقة عالية في التعرف

## 🔧 حل المشاكل

### المشكلة: "لا يتعرف على الموظف"

**الحلول:**
1. تأكد من وجود 5-10 صور متنوعة
2. تأكد من جودة الصور (واضحة، حادة)
3. خفّض الـ threshold في `config/face_recognition_config.json`:
   ```json
   "threshold": 0.65
   ```
4. أعد التدريب

### المشكلة: "يتعرف على موظف خطأ"

**الحلول:**
1. ارفع الـ threshold:
   ```json
   "threshold": 0.75
   ```
2. أضف صور أكثر تنوعاً
3. احذف الصور المشابهة جداً

### المشكلة: "File not found: face_encodings.pkl"

**الحل:**
```bash
# لم تقم بالتدريب بعد!
python train_faces.py
```
