## ⚡ البدء السريع جداً

### 1. تطبيق الويب (الأسهل)

```bash
python run_web_app.py
```

ثم افتح: http://127.0.0.1:5000

**تسجيل الدخول:**
- المستخدم: `admin`
- كلمة المرور: `admin`

### 2. النظام الكامل (مع فيديو)

```bash
python src/main_production.py \
    --source videos/test.mp4 \
    --enable-face-recognition \
    --enable-activity-recognition \
    --display
```
