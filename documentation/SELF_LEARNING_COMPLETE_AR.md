# 🧠 نظام التعلم الذاتي الكامل
## دليل النظام الشامل

---

## 📊 نظرة عامة

نظام التعلم الذاتي المتكامل لتحسين دقة التعرف على الموظفين تلقائياً من خلال:
- **جمع البيانات التلقائي** - 10-20 صورة/يوم لكل موظف
- **تقييم الجودة الذكي** - فلترة الصور المنخفضة الجودة
- **التعلم النشط** - تأكيد بشري للحالات المشكوك فيها
- **التدريب المستمر** - تحديث النموذج تلقائياً
- **المراقبة والتنبيهات** - صحة النظام بشكل مستمر

## 📦 المكونات الأساسية

### 1. قاعدة البيانات (`database.py`)
**الجداول:**
- `training_images` - الصور التدريبية المجمعة
- `human_corrections` - التصحيحات البشرية
- `confirmation_queue` - قائمة انتظار التأكيد
- `model_performance` - مؤشرات أداء النموذج

**الإحصائيات:**
- إجمالي الصور: 9
- الصور المؤكدة: 0
- متوسط الجودة: 89.6%
- متوسط الثقة: 86.2%

### 2. نظام التخزين (`storage.py`)
**المجلدات:**
```
training_data/
├── raw/           # الصور الخام
│   ├── EMP001/
│   ├── EMP002/
│   └── ...
├── validated/     # الصور المؤكدة
└── rejected/      # الصور المرفوضة
```

**المميزات:**
- تسمية تلقائية منظمة
- قص الوجوه تلقائياً
- نقل بين الفئات
- تنظيف تلقائي

### 3. مُقيِّم الجودة (`quality_assessor.py`)
**المقاييس:**
- **الوضوح** (Laplacian) - 50+ مقبول
- **الإضاءة** - 60-200 مقبول
- **حجم الوجه** - 80px+ مقبول
- **زاوية الوجه** - <30° مقبول
- **الدرجة الإجمالية** - 60%+ مقبول

**معدل القبول:** ~60%

### 4. مُجمِّع البيانات (`data_collector.py`)
**السياسات:**
- ثقة دنيا: 80%
- حد أقصى يومي: 20 صورة/موظف
- فاصل زمني: 5 دقائق بين الصور
- أقصى لكل جلسة: 3 صور

**الإضافة التلقائية للقائمة:**
- ثقة 70-85% → قائمة التأكيد
- فرق قليل بين التوقعات → قائمة التأكيد

### 5. التدريب المستمر (`continuous_trainer.py`)
**شروط التدريب:**
- 50+ صورة جديدة مؤكدة، أو
- 10+ تصحيحات بشرية، أو
- دقة < 85%، أو
- مضى 24 ساعة

**الفاصل الزمني:** 24 ساعة افتراضياً
**الجدولة:** 2 صباحاً، 2 ظهراً

### 6. نظام المراقبة (`monitoring.py`)
**الفحوصات:**
- معدل جمع البيانات
- حالة قائمة التأكيد
- جودة الصور
- أداء النموذج
- التصحيحات البشرية
- مساحة التخزين

**مستويات التنبيه:**
- 🔴 **Critical** - مشكلة حرجة
- 🟠 **Error** - خطأ
- 🟡 **Warning** - تحذير
- 🔵 **Info** - معلومة

**درجة الصحة:** 0-100%
- 90-100: ممتاز 🟢
- 75-89: جيد 🔵
- 60-74: متوسط 🟡
- 0-59: يحتاج انتباه 🔴

## 🌐 الواجهات

### 1. لوحة الإحصائيات
**URL:** `http://127.0.0.1:5000/self-learning`

**المحتوى:**
- عدد الصور (إجمالي، مؤكدة)
- متوسط الجودة والثقة
- قائمة التأكيد (معلقة، مؤكدة، مرفوضة)
- التصحيحات البشرية
- أداء النموذج الأخير

### 2. قائمة التأكيد
**URL:** `http://127.0.0.1:5000/self-learning/confirmation/queue`

**المميزات:**
- عرض الصور المعلقة
- أفضل 3 توقعات لكل صورة
- أشرطة الثقة
- فلترة حسب الأولوية
- أزرار الإجراءات:
  - ✓ تأكيد
  - ✗ رفض
  - 🔄 اختيار بديل

### 3. لوحة المراقبة
**URL:** `http://127.0.0.1:5000/self-learning/monitoring`

**المحتوى:**
- درجة صحة النظام
- عدد التنبيهات (عاجل، أخطاء، تحذيرات)
- قائمة التنبيهات المفصلة
- الطوابع الزمنية

## 🔧 API Endpoints

### GET `/self-learning/api/stats`
إحصائيات عامة للنظام

**Response:**
```json
{
  "images": {
    "total": 9,
    "validated": 0,
    "avg_quality": 0.896,
    "avg_confidence": 0.862
  },
  "queue": {
    "pending": 9
  },
  "corrections": 0
}
```

### POST `/self-learning/api/confirm`
تأكيد أو رفض صورة

**Request:**
```json
{
  "queue_id": 1,
  "action": "confirm",  // confirm, reject, correct
  "employee_id": "EMP001"  // للتصحيح
}
```

### POST `/self-learning/api/train`
تشغيل التدريب

**Request:**
```json
{
  "force": true  // إجبار التدريب
}
```

**Response:**
```json
{
  "success": true,
  "message": "تم التدريب بنجاح",
  "performance": {
    "model_version": "v1.0.1",
    "accuracy": 0.92,
    "f1_score": 0.91
  }
}
```

### GET `/self-learning/api/training-stats`
إحصائيات التدريب

### GET `/self-learning/api/monitoring/health`
درجة صحة النظام

**Response:**
```json
{
  "health_score": 91.0
}
```

### GET `/self-learning/api/pending-count`
عدد الحالات المعلقة

## 📝 سير العمل

### 1. جمع البيانات
```
كاميرا → تعرف على وجه → فحص الثقة والجودة
   ↓
[مقبول] → حفظ في training_data/raw/
   ↓
إضافة لقاعدة البيانات
   ↓
[ثقة منخفضة] → إضافة لقائمة التأكيد
```

### 2. التأكيد البشري
```
مستخدم يفتح /confirmation/queue
   ↓
يرى الصورة + أفضل 3 توقعات
   ↓
يختار: تأكيد | رفض | تصحيح
   ↓
حفظ في قاعدة البيانات + تحديث الحالة
```

### 3. التدريب المستمر
```
كل 24 ساعة أو عند توفر بيانات كافية
   ↓
فحص: 50+ صورة جديدة أو 10+ تصحيحات
   ↓
[نعم] → تحضير البيانات → تدريب النموذج
   ↓
حفظ مؤشرات الأداء
   ↓
تعليم الصور كمستخدمة
```

### 4. المراقبة
```
كل ساعة أو عند الطلب
   ↓
تشغيل 6 فحوصات
   ↓
تصنيف التنبيهات (critical → info)
   ↓
حساب درجة الصحة
   ↓
عرض في لوحة المراقبة
```

## ⚙️ الإعدادات

### إعدادات الجمع (`DataCollector`)
```python
collector = DataCollector(
    max_images_per_day=20,      # الحد الأقصى اليومي
    min_confidence=0.80,         # الحد الأدنى للثقة
    auto_add_to_queue=True       # إضافة تلقائية للقائمة
)
```

### إعدادات الجودة (`QualityAssessor`)
```python
assessor = QualityAssessor(
    min_sharpness=50.0,          # الحد الأدنى للوضوح
    min_brightness=60.0,         # الحد الأدنى للإضاءة
    max_brightness=200.0,        # الحد الأقصى للإضاءة
    min_face_size=80,            # الحد الأدنى لحجم الوجه
    max_face_angle=30.0          # الحد الأقصى لزاوية الوجه
)
```

### إعدادات التدريب (`ContinuousTrainer`)
```python
trainer = ContinuousTrainer(
    min_new_images=50,           # الحد الأدنى للصور الجديدة
    min_corrections=10,          # الحد الأدنى للتصحيحات
    auto_retrain=True,           # التدريب التلقائي
    training_interval_hours=24   # الفاصل الزمني
)
```

### الجدولة (`TrainingScheduler`)
```python
scheduler = TrainingScheduler(
    schedule_hours=[2, 14]       # ساعات التدريب (2 صباحاً، 2 ظهراً)
)
```
