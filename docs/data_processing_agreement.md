# اتفاقية معالجة البيانات (DPA)

هذه الاتفاقية تبيّن الأدوار والمسؤوليات بين "المؤسسة" (مالك النظام) و"معالج البيانات" (مدير النظام/المزوّد)، فيما يتعلق بمعالجة بيانات الموظفين عبر نظام مراقبة الموظفين بالذكاء الاصطناعي.

## الأطراف
- *المتحكم بالبيانات*: المؤسسة.
- *المعالج*: فريق تقنية المعلومات أو المزود الخارجي (إن وجد).

## نطاق المعالجة
- فئات البيانات: صور الوجه، سجلات الحضور، نشاط العمل (مؤشرات)، سجلات تقنية.
- الغرض: إدارة الحضور، الأمان، والتحليل التشغيلي.
- مدة المعالجة: وفق سياسة الاحتفاظ المنصوص عليها.

## التعليمات والامتثال
- يلتزم المعالج بتنفيذ المعالجة فقط وفق تعليمات المتحكم.
- الالتزام بجميع القوانين واللوائح المعمول بها (مثل GDPR عندما يكون مناسباً).

## الأمان
- تطبيق ضوابط أمنية مناسبة: تشفير البيانات، التحكم في الوصول، سجلات التدقيق.
- إعلام المتحكم بأية خروقات أمنية على وجه السرعة.

## السرية
- يلتزم المعالج بالحفاظ على سرية البيانات وعدم الإفصاح عنها إلا بإذن المتحكم أو وفق القانون.

## حقوق الأفراد
- دعم المتحكم في الاستجابة لطلبات الحقوق (الوصول، التصحيح، الحذف، التقييد، الاعتراض).

## النقل والجهات الفرعية
- عدم نقل البيانات إلى جهات فرعية أو خارج الحدود دون موافقة المتحكم والامتثال للوائح.

## الإنهاء
- عند انتهاء الخدمة، حذف أو إعادة جميع البيانات الشخصية للمتحكم وفق تعليماته.
