## 🎓 المصطلحات

### ما هو "التضمين" (Embedding)?
```
صورة الوجه → النموذج → 512 رقم
هذه الأرقام تمثل الوجه رياضياً
```

**مثال:**
```python
photo1.jpg → [0.234, -0.891, 0.456, ...] (512 رقم)
photo2.jpg → [0.238, -0.887, 0.461, ...] (512 رقم)
# رقمان متقاربان = نفس الشخص ✅
```

### Pre-trained Model (نموذج مُدرَّب مسبقاً):
- نموذج تم تدريبه من قبل خبراء
- على ملايين الصور
- جاهز للاستخدام فوراً
- لا تحتاج إعادة تدريبه

### Transfer Learning (التعلم بالنقل):
- استخدام نموذج جاهز
- تطبيقه على بياناتك الخاصة
- بدون تدريب من الصفر
- **هذا ما تفعله بالضبط!**
