## 🚀 البدء السريع

### **1. التثبيت (5 دقائق):**
```bash
# استنساخ المشروع
git clone [repository-url]
cd employee-monitoring-ai

# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل النظام
python run_web_app.py
```

### **2. الوصول للنظام:**
```
🌐 افتح المتصفح: http://localhost:8080
👤 تسجيل الدخول: admin / admin
🎥 اختبار: اذهب إلى /test-video
```

### **3. اختبار سريع:**
```bash

python quick_test.py

# اختبار المعالج
python test_processor.py
```

## 🛠️ البنية التقنية

### **المعالج الرئيسي:**
```python
from src.level2_video_processor import Level2VideoProcessor

processor = Level2VideoProcessor(
    enable_advanced_ai=True,
    enable_face_recognition=True,
    enable_activity_recognition=True
)
```

### **المكونات الأساسية:**
- `Level2VideoProcessor` - المعالج المتقدم
- `AdvancedBehaviorAI` - الذكاء الاصطناعي
- `FaceRecognitionSystem` - التعرف على الوجوه
- `ActivityRecognizer` - كشف الأنشطة

### **قاعدة البيانات:**
- SQLite للبيانات المحلية
- JSON للإعدادات
- ملفات الصور في `static/uploads/`
